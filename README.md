# SCTMG Soundboard

Веб-саундборд для настольной игры **StarCraft: The Miniatures Game** — реплики юнитов
для атмосферы и шуток за столом. Мобильно-ориентированный интерфейс, статический сайт
(HTML/CSS/JS без сборки), можно открыть прямо с GitHub Pages.

Помимо 20 юнитов самой настолки (кнопка **TMG** в шапке — вкл/выкл), сайт целиком
покрывает весь ростер **StarCraft II** и оригинального **StarCraft (1998)**: 155 юнитов,
три языковых/версионных пака (EN/RU для SC2, «SC1» для классики), плюс вкладка с фоновой
музыкой из обеих игр.

## Запуск локально

Нужен только Node.js (для локального сервера). Из корня проекта:

```bash
npx serve .
```

и открыть `http://localhost:3000` (или тот порт, который покажет `serve`).

Сайт полностью статический, так что подойдёт и любой другой способ раздать файлы
(`python -m http.server`, расширение Live Server и т.п.) — просто не открывайте
`index.html` напрямую как `file://`, `fetch()` для `data/*.json` не сработает без сервера.

## Структура

```
index.html                разметка
css/style.css             стили (тёмная тема, мобильный интерфейс)
js/app.js                 вся логика: рендер, поиск, избранное, языки, музыка
data/units.json           список юнитов, факций, подписи категорий (редактируется руками)
data/quotes.en.json       реплики EN (генерируется скриптами, см. ниже)
data/quotes.ru.json       реплики RU
data/quotes.classic.json  реплики "классика" (SC1)
data/music.json           плейлист фоновой музыки
assets/audio/en|ru|classic/   сами .mp3 файлы реплик, по языку/факции/юниту
assets/music/sc2|sc1/         .mp3 фоновой музыки, по игре
scripts/                  служебные ноды-скрипты для сбора данных (не часть сайта)
```

## Откуда звуки

Два источника, оба уже прогнаны один раз — результат лежит в `assets/audio/en` и
`data/quotes.en.json`, перезапускать не нужно если не меняется набор юнитов.

**1. Текст реплик (11 юнитов с говорящей озвучкой: Marine, Marauder, Medic, Goliath,
Raynor, Zealot, Adept, Sentry, Stalker, Artanis×2, Hydralisk)** — с `starcraft.fandom.com`
(вики, текст под CC-BY-SA), скриптом `scripts/download-audio.mjs` (нужен заранее
собранный `data/quotes.en.raw.json` — вики за Cloudflare, простым `curl`/`node fetch`
не открывается, шаблоны пришлось тянуть через реальный браузер один раз вручную; сами
`.ogg` после этого скачиваются откуда угодно с `static.wikia.nocookie.net`).

**2. Всё остальное — извлечено напрямую из игровых файлов** через
`scripts/casc-extract-all.mjs` и пакет `@jamiephan/casclib` (нативные Node-биндинги к
CascLib, читает архив CASC игры без каких-либо GUI-инструментов). Отсюда взяты:

- Голоса юнитов, которых не было на вики: **Zergling, Roach, Queen, Kerrigan**
  (у Kerrigan даже текст реплик подтянут — он был в вики отдельным блоком не в виде
  переиспользуемого шаблона, поэтому автоскрейпер его пропустил, а вручную сопоставить
  оказалось можно один в один по номерам файлов). Из 29 реплик Kerrigan у 13 файлов
  оказался битый/отсутствующий размер прямо в архиве игры (не наша проблема — сама
  Blizzard недокомплектовала), поэтому у неё сейчас 16 из 29.
- **Реальные звуки атаки** (выстрелы/удары оружия, категория «Бой» на каждой карточке) —
  отдельно от голосовых «Атака!»-реплик, это буквально звук выстрела/удара по цели.
  Есть почти у всех юнитов с оружием; Medic, Sentry, Raynor, Roachling, Kerrigan — без
  урона или без отдельного файла в игре, пропущены осознанно.

Игра хранит часть звуков в IMA ADPCM `.wav`, который браузеры не воспроизводят —
`scripts/transcode-wav.mjs` (через `ffmpeg-static`) перегоняет их в `.ogg`, уже
применено, новых `.wav` в проекте нет.

Как повторить/расширить (например, добавить ещё юнита или языковой пакет):
`node scripts/casc-search.mjs "имя_юнита" ".ogg"` — найдёт все совпадающие пути в
архиве и сохранит в `scripts/_casc-search-out.txt`; `casc-list-dir.mjs` — то же самое
по подстроке пути. Дальше вручную выбрать нужные пути и дописать в `casc-extract-all.mjs`
(или дёрнуть `storage.readFileAsync()` напрямую).

**3. Русская озвучка** (`data/quotes.ru.json`, `assets/audio/ru/`) — скриптом
`scripts/casc-extract-ru.mjs`. Для каждой строки из EN-пака ищет её файл в
`enus.sc2assets`-папке архива и подменяет локаль на `ruru.sc2assets` (та же папка,
тот же файл, просто на другом языке). Юниты без настоящей озвучки (Hydralisk, Sentry,
Zergling, Roach, Queen — у них не речь, а универсальный рык/писк без локализации)
просто переиспользуют EN-файл, звук всё равно один и тот же независимо от языка.
Подписи к репликам везде остаются на английском (текста для RU/классики нигде нет,
это просто ярлык, чтобы понимать, что играет).

**4. «Классика» (SC1, 1998 год)** — `data/quotes.classic.json`, `assets/audio/classic/`.
У архива StarCraft: Remastered (`D:\Program Files (x86)\StarCraft`, тоже CASC) **нет
таблицы имён файлов** — только хэши, `casclib` не может ни перечислить, ни открыть файл
по имени, даже когда имя точно известно (проверено — `fileExists`/`readFileAsync` не
резолвят вообще ничего, ни с одним из вариантов пути/регистра/расширения). Поэтому два
источника:
  - **Текст + большая часть голосов юнитов** — с той же вики, шаблоны с суффиксом `SC1`
    (`Template:QuotesSC1Marine` и т.п.), тем же методом, что и EN-пак.
  - **Всё, чего нет на вики (в первую очередь звуки атаки/удара) — вручную извлечено
    пользователем через [Ladik's MPQ Editor](http://www.zezula.net/en/mpq/download.html)**
    (у него, в отличие от `casclib`, получилось открыть этот CASC-стор). Внутри архив
    хранит оригинальные MPQ-пути с префиксом `SD\` (StarDat) — например,
    `SD\sound\bullet\blastcan.wav`. Извлечённая папка `sound\bullet` (62 файла, короткие
    восьмисимвольные DOS-имена вида `tmafir00.wav`) размечена вручную по префиксам
    (`tma`=Terran MArine, `zqu`=Zerg QUeen и т.п.) скриптом `scripts/build-sc1-sfx.mjs` —
    51 из 62 файлов уверенно опознаны и разложены по юнитам в категорию «Бой», остальные
    (`blastcan`, `shcklnch`, `pshield`...) слишком неоднозначны без документации и не
    привязаны нигде, чтобы не гадать.

**5. Полный ростер обеих игр** (`scripts/build-full-roster.mjs`) — помимо 17 юнитов
самой настолки, вика содержит шаблоны реплик почти на весь ростер SC2 (123 юнита —
`starcraft.fandom.com/wiki/StarCraft_II_unit_quotations/{Terran,Protoss,Zerg}`, поиск
шаблонов через MediaWiki API `list=allpages&apnamespace=10&apprefix=QuotesSC2`, а не
парсинг те же трёх страниц-индексов) и весь ростер SC1 (64 юнита, `QuotesSC1*` тем же
способом). Юниты, уже присутствующие в кураторском наборе (см. `SC{1,2}_OVERLAP` в
скрипте), не перезаписываются — только 138 новых. У новых юнитов нет отдельного
русского имени (`name` = `subtitle` = английский label с вики) — не наша забота
переводить весь SC2/SC1, но легко доправить руками в `data/units.json`, если понадобится
для конкретного юнита. Флаг `tmg: false`/`games: ['sc1'|'sc2']` на каждом юните — кнопка
**TMG** в шапке фильтрует список по `tmg`, а смена языка/версии (EN/RU ⇄ SC1) — по `games`
(RU-пак не расширялся на всех 138 — там как был, так и остался только кураторский набор,
для новых юнитов в RU покажется пустая карточка «звуков пока нет»).

**6. Фоновая музыка** (`data/music.json`) — вкладка «🎵 Музыка», играет независимо от
остального сайта (не останавливается при переключении вкладок), мини-плеер снизу экрана
с перемоткой по клику. Два переключаемых списка:
  - **SC2** (`assets/music/sc2/`, `scripts/casc-extract-music.mjs`) — 22 трека, вручную
    отобраны из движковой библиотеки `assets\music\` архива SC2 (та же музыка что и в
    кампании, и в фоне мультиплеера). Часть музыки в игре — порезанные на "слои", которые
    движок сводит динамически по ходу боя (например «Fury» — это файлы `a.ogg`…`h.ogg`),
    из каждой такой группы взят один представительный кусок.
  - **SC1** (`assets/music/sc1/`, `scripts/build-sc1-music.mjs`) — 23 трека (Terran/
    Protoss/Zerg I–IV, Title, Ready Room/Victory/Defeat на каждую расу, «Radio Free
    Zerg»), тем же способом извлечены пользователем через MPQ Editor (папка `music\` в
    архиве — без префикса `SD\`, отдельная от юнитовых звуков, уже в приличном качестве
    Ogg Vorbis) и просто перегнаны в mp3.

### Юниты без звука

**Roachling** — в игровых файлах нет отдельных звуков для него вообще (маленький
summon-юнит, использует чужие эффекты без своих файлов), в `data/units.json` остался
`"pending": true`.

Point Defense Drone, Pylon, Omega Worm сознательно не добавлены — это не голосовые
юниты (дрон/пилон/червь без реплик), для них имел бы смысл только звук
срабатывания/рёва, отдельная небольшая задача при желании.

## Авторские права

Голоса и звуки — собственность Blizzard Entertainment, часть игровых файлов
StarCraft II. Сайт задуман для личного некоммерческого использования (партии
в настольную игру), лежит открыто в репозитории по решению автора проекта.

Скриптам из `scripts/` нужен `npm install` (ставит `@jamiephan/casclib` и
`ffmpeg-static` — только для сборки данных, самому сайту эти пакеты не нужны,
`node_modules` не коммитится, см. `.gitignore`).

## Что дальше (не сделано)

- 11 из 62 файлов `sound\bullet` не привязаны ни к одному юниту (слишком
  неоднозначные короткие имена без документации) — при желании можно опознать точнее.
- RU-пак не расширён на полный ростер, только на кураторский набор из 17 юнитов.
- Point Defense Drone / Pylon / Omega Worm — эффекты без голоса, не добавлены.
- "Стоп всё" и "случайная реплика юнита одной кнопкой" — сознательно отложены
  пользователем, но архитектура (`js/app.js`) легко расширяется под них.
